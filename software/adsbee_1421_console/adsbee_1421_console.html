Firmware Update

Flashing erases the current app image. The device will not run until a flash completes successfully (the ROM bootloader stays available for retries — the board cannot be bricked by this process).

  1. Wire the adapter to the module: TX → SURX (pin 20, DIO_2), RX → SUTX (pin 21, DIO_3), and ground to ground.
  2. Hold SYNC (pin 28, DIO_5) high at 3.3 V.
  3. With SYNC still high, reset the module: pull RESET_N (pin 17) low briefly, or power-cycle it.
  4. Release reset. SYNC can stay high — the boot ROM samples it only at boot.
  5. Press Check bootloader below.

The baud rate does not need to match: the ROM locks onto whatever rate this page sends its sync bytes at. If the SYNC pin is unreachable, running AT+BOOT_UART_BOOTLOADER=1DEADBEE in the console also enters the bootloader, but it erases the vector table, so the device stays there until it is reflashed.
