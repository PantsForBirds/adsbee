Method

  • Firmware. Branch t0879 a831d5ee: t0872 0a93bd43 (#398 + c91a63d9 + main) plus worker-3's ADSBEE_LAB_RX counters (t0875) and AT+LABRAW. Checked before each start: FIRMWARE 0xBB998689, CONFIG_HASH 0x02FEF0CF, SETTINGS_FULL 0x4DB591F5. Afterward the original rc9 was restored and verified (flash sha256, hashes, settings dump identical).
  • Schedule. 16:30–19:00 UTC (round 1), pause for worker-1, 22:30–09:26 UTC (rounds 2–5 and the learner). Each arm once per round, order rotated. The TL offset was set at runtime only. The first 60 s of each block are skipped. Rounds 4–5 fell in night traffic.
  • Trend model. Weighted least squares on log(metric): an arm effect plus a smooth time trend (linear in the first sitting; a linear spline with 2 h knots in the second), weighted by aircraft in the block. Distance bins are weighted by aircraft in that bin. A version on the first 16 blocks only (busy traffic) gives the same signs.
  • Metrics. Good frame = CRC-valid Mode S. Aircraft = ICAO with ≥2 good frames. Seen once = ICAO with one good frame (likely false decodes). CPR jumps = position fixes >2 nm + 0.2 nm/s off the track. Range is measured from the median of all decoded positions, since no receiver position is configured; it compares arms only. Demod CPU = core-1 demod time ÷ block time.
  • Comparator. AT+LABDUTY (HI fraction, rising edges; 136 ns/read, undercounts single-read spikes) and AT+LABRAW (96 raw 45 µs captures per block, 88 ns/read). On signal = 10 µs before to 125 µs after a pulse ≥0.35 µs.
  • Scripts. ana/ab79.py, ana/trend79.py, ana/ratios79.py, ana/lraw.py, ana/make_report79.py; on-Pi kit in kit/. Logs: /workspace/agents/worker-5/t0879/data/final/runs/.
